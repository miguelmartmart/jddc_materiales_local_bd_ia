## Resumen y Próximos Pasos

He creado una función `detect_malware()` que intenta detectar malware utilizando un enfoque heurístico simple. La función verifica si existe un archivo llamado `malware.txt`. Si existe, imprime un mensaje indicando que se está analizando y luego imprime "Malware detected!". Si no existe, imprime un mensaje indicando que no se detectó malware. La función incluye un bloque `try...except` para manejar posibles errores durante el análisis. Ahora, debes ejecutar el script `detect_malware.py` con el comando `python detect_malware.py` en tu terminal. Después de ejecutar el script, deberás abrir el navegador web y visitar la URL `http://localhost:8000/` para ver el resultado.
